# 分层窗口渲染

网格、按钮和小地图由同一个顶层分层窗口绘制。网格采用较低 Alpha，按钮和小地图
采用较高 Alpha；没有画布模式时整个帧清为透明，让鼠标正常穿透。

## ULW + GDI+ 的 Alpha 陷阱

2026-10-07，由 richie 定位修复。

`Graphics.FromHdc(dc)` 上 Alpha=255 的不透明填充会走 GDI 快速路径，把像素 Alpha
写成 0。分层窗口的命中测试按 Alpha 值处理：这会把刚画出的高亮色块变成点击穿透洞。
症状是悬停高亮的色块点不中，周围空白反而能通过就近命中触发跳转。

正确路径是：

1. 使用 `CreateDIBSection` 分配 top-down 的 32bpp 像素缓冲。
2. 使用 `new Bitmap(w, h, stride, Format32bppPArgb, pixels)` 包装同一段内存。
3. 只通过 `Graphics.FromImage` 绘制，保留真实 Alpha。
4. 将同一张 DIB 选入内存 DC，使用 `UpdateLayeredWindow` 呈现。

PArgb 满足分层窗口的预乘 Alpha 要求，绘制与呈现共享像素，不需要每帧复制 HBITMAP。
释放时先释放托管 Bitmap 包装，再释放它依赖的原生位图和 DC。

## 刷新与输入

拖拽期间合并鼠标移动量，每 16ms 更新一次镜头。平移刷新网格和小地图；悬停时小地图只重绘自身区域，但
`UpdateLayeredWindow` 仍提交完整帧；它不是局部区域提交接口。

小地图绘制与命中共用矩形列表，当前保留 44 像素的就近选择范围。这解释了点击
色块附近空白也会选中窗口；修改容差时应同步验证重叠色块、边缘和鼠标光标反馈。

## 实时缩放

缩放使用独立的不激活普通窗口承载 DWM 缩略图，原来的共享 DIB 分层窗口仍位于最上方，
绘制网格、提示、按钮、小地图并接收输入。DWM 目标窗口不使用 `UpdateLayeredWindow`。
窗口内容与网格应用同一个视口变换，小地图白框显示当前世界坐标视口及比例。

预览按原窗口层级排列，命中检测反向遍历同一目标矩形列表。拖动距离除以当前比例，
滚轮每格乘以 1.15，支持不足一格的高精度输入。25% 可以查看完整 3×3 画布；最大 200%。
预览不可用时显示可点击占位提示；退出缩放和应用退出均释放 DWM 句柄。
画布模式期间启用鼠标滚轮钩子，仅转发指针位于分层输入窗口上的滚轮消息；
离开画布时卸载，避免依赖系统“滚动非活动窗口”开关。钩子只投递消息，不直接渲染。

可选屏幕验证：`dotnet run --project tests/Desktop -c Release -- --preview-screenshot`。
仅显示独立测试窗口，验证实际缩放像素并将截图写入临时目录。

## 桌面图标

图标启用后由独立分层窗口绘制，层级置于 Explorer 桌面上方、其他应用下方。
背景保持 Alpha=0；图标单元格使用 Alpha=1 的填充保证透明边缘也可点击。
共享 DIB 包装方式与原画布一致，资源按 Bitmap → HBITMAP → DC 顺序释放。
图标采用同一视口变换，缩放时在 DWM 宿主背景绘制；命中矩形和显示保持一致。
应用预览覆盖图标时优先命中应用，图标双击打开，拖动只改变世界坐标。
小地图图标使用紫色块，点击定位镜头；无限模式的小地图范围动态包含内容和视口。
