# PaneSpace · 窗域

把应用窗口放进一张可浏览的桌面画布。**桌面前台按住 Ctrl**，即可拖动网格，
默认浏览覆盖 **3 × 3 个主屏区域**的工作空间；托盘设置中开启“无限画布”后取消镜头边界。
通过小地图可以找到窗口并跳转过去。

100% 时平移直接移动真实窗口，保留原有尺寸和应用交互。滚轮以鼠标位置为中心，
通过实时窗口预览实现 25%–200% 缩放；松开 Ctrl 或点击预览窗口后回到 100%，
继续操作原应用。

## 功能

- **拖拽平移**：在画布中浏览窗口，无需逐个搬动。
- **可选屏幕边缘平移**：鼠标停在屏幕工作区边缘后自动移动镜头，无需按 Ctrl；默认关闭，可在设置中开启。
- **可选无限画布**：镜头可向任意方向持续平移，小地图自动包含镜头和全部内容；自动排列仍使用九屏区域。
- **可选桌面图标**：将桌面文件、文件夹、快捷方式及系统项目纳入画布，支持拖动位置和双击打开。
- **滚轮缩放**：25%–200% 浏览实时窗口内容，网格和小地图视口同步变化，原窗口尺寸保持不变。
- **交互小地图**：点击窗口色块，镜头居中并激活对应窗口。
- **任务栏跟随**：点击任务栏图标或缩略图还原、激活窗口后，镜头自动跟随，受画布边界限制。
- **瀑布流排列**：将不同尺寸的窗口放到最低可用位置，支持宽窗口跨列，保持窗口尺寸。
- **整屏平铺**：每个窗口调整到一个主屏格子内，四个边距可分别设置，默认上、左、右 28px、下方 80px；格子按三列相邻排列，无限模式超过九个窗口继续增加行。
- **布局存档**：记住镜头偏移、窗口位置、图标位置和设置，供下次启动恢复。
- **托盘控制**：通过 PaneSpace 托盘图标打开设置、复位或退出。
- **退出收回窗口**：保存画布布局后，将画布窗口搬回可见工作区；最小化窗口保持最小化，
  修正其还原位置，避免后续还原到屏幕外；可见的所属对话框也会一起收回。

## 构建与运行

开发需要 **Windows、PowerShell 7 和 .NET 10 SDK**。生产发布为 **Windows x64 自包含单 EXE**，
内置 .NET 运行时，直接复制 `dist/PaneSpace.exe` 即可运行，无需额外安装运行时。

```powershell
git clone https://github.com/lisniuse/PaneSpace.git
cd PaneSpace
pwsh -NoProfile -File scripts/publish.ps1
.\dist\PaneSpace.exe
```

启动时接受管理员权限提示，以便管理提权运行的应用窗口。程序启动后驻留托盘，
不打开独立主窗口。

发布脚本先构建和运行检查，再结束运行中的 PaneSpace / 旧名 CamCanvas 进程，
统一输出为 **`dist/PaneSpace.exe`** 单文件。`build.cmd` 提供同样的发布入口。仓库不包含构建产物。

## 操作

| 操作 | 效果 |
| --- | --- |
| 桌面前台按住 Ctrl | 显示网格、按钮栏和交互小地图 |
| 左键拖动网格 | 平移画布 |
| 画布模式下滚轮 | 以鼠标位置为中心，25%–200% 缩放 |
| 点击缩放后的窗口预览 | 回到 100%，居中并激活对应窗口 |
| 缩放后松开 Ctrl | 围绕当前视图中心回到 100% |
| 点击小地图中的窗口色块 | 镜头居中并激活该窗口 |
| 从任务栏唤起窗口 | 跟随还原或激活的窗口 |
| 自动排列(全画布) | 在 3×3 九屏区域排列可见、未最小化的窗口；无限模式也保持此规则 |
| 整屏平铺 | 按保存的上、右、下、左边距调整窗口大小并排列 |
| 拖动画布中的桌面图标 | 调整并保存图标的画布位置 |
| 双击画布中的桌面图标 | 打开文件、文件夹或快捷方式 |
| 点击小地图中的紫色图标块 | 镜头居中定位该图标 |
| 托盘 → 设置… | 设置画布选项及整屏平铺的四个边距 |
| 开启边缘平移后，鼠标停在工作区边缘 | 无需按 Ctrl，短暂停留后自动平移镜头 |
| 全部搬回中心屏 | 保持相对布局，整体移回中心屏 |
| 复位按钮 / 托盘 → 画布归位 | 回到 100%，将镜头偏移归零 |
| 托盘退出 | 保存画布布局，将窗口收回屏幕后退出 |

当前工具栏和托盘菜单使用中文。排列放不下所有符合条件的窗口时，会保留原布局并提示。
Esc 不再触发镜头归位或移动窗口；需要归位时使用复位按钮或托盘菜单。

**整屏平铺**会回到 100% 并将首个格子居中展示。四个边距可在设置中修改，默认每格
上、左、右各留 28px，下方留 80px。相邻窗口横向间距为“左 + 右”，纵向间距为
“上 + 下”，默认分别为 56px 和 108px。
有限模式最多放九个窗口，超过时保留整个原布局并提示；无限模式
按三列继续增加行。最大化窗口会先还原，再调整大小；隐藏、最小化窗口不参与。
有尺寸限制的应用按实际接受的大小，在预留边距后的可用区域内居中，受限或调整失败时给出托盘提示。
桌面图标的画布位置保持不变。原来的瀑布流“自动排列”保持原有行为。
通过小地图或任务栏再次定位平铺窗口时保留该次布局的边距；手动改变窗口尺寸后恢复普通居中。

## 设置

右键托盘图标 → **设置…**，三个选项可独立勾选，点击“保存”生效：

- **无限画布**：取消九屏镜头边界；关闭时将越界内容收回有限画布范围。
  无论是否开启，自动排列都仍按原来的 3×3 九屏区域执行。
- **桌面图标**：软件运行期间用画布图标层显示桌面项目，随镜头平移和缩放，
  支持拖动、双击打开及位置存档；新增或删除的桌面项目会刷新。
- **屏幕边缘平移**：无需按 Ctrl，鼠标在主屏工作区边缘 12px 内停留 250ms 后，
  镜头向相应方向移动，角落支持斜向移动；底部触发边缘位于任务栏上方。
  拖动、按鼠标键、使用菜单或任务栏、打开设置期间暂停。原生窗口和缩放预览均支持，有限模式遵守画布边界。

**整屏平铺边距（px）**：上、右、下、左四个值可独立设置，默认依次为 **28、28、80、28px**。
可设置为 0；左右之和必须小于主屏宽度，上下之和必须小于主屏高度。
保存后，再次点击 **整屏平铺** 使用新边距；修改设置时保留现有窗口布局。
四个值会保存，旧设置自动采用上述默认值。

三个开关首次默认都不勾选；旧设置中边缘平移默认关闭。关闭桌面图标选项或退出软件后恢复 Windows 原桌面的显示状态和布局；
异常退出时由恢复进程还原原图标视图。桌面文件本身不会被移动或重命名。

## 开发

```powershell
pwsh -NoProfile -File scripts/build.ps1
pwsh -NoProfile -File scripts/test.ps1
```

检查直接引用实际的 Core 库，覆盖最短列、宽窗口跨列、边界、空间不足及
1000 组固定种子的随机布局。测试是可执行程序，请使用 `scripts/test.ps1`，而非 `dotnet test`。
原生桌面检查使用独立测试窗口，验证普通、最小化、最大化、部分出屏和超大窗口的退出收回行为。
缩放检查覆盖鼠标锚点、比例限制、拖动距离、实时缩略图、滚轮消息、原窗口尺寸及输入层 Alpha。
另有无限镜头、小地图动态范围、图标输入与渲染、设置窗口、原子存档及旧数据兼容检查。
整屏平铺检查覆盖边距、有限模式超限、无限模式续行、最大化窗口、应用尺寸限制及缩放中的按钮输入。
另有四边不同值、零边距、无效边距组合、设置存档及自定义边距下的窗口定位检查。
边缘平移检查覆盖方向、停留计时、暂停、斜向速度、缩放及有限/无限边界。
CI 还会发布并启动实际生产单 EXE。

无需移动用户窗口即可验证单 EXE：

```powershell
pwsh -NoProfile -File scripts/verify-package.ps1
```

接受 Windows 管理员权限提示后，检查内置 UI/图标、Core、DWM 预览及恢复子进程，再退出。

## 布局数据

布局写入 `%LOCALAPPDATA%/PaneSpace/state.json`。新位置没有存档时，会读取旧的
`%LOCALAPPDATA%/CamCanvas/state.json`；后续保存使用新位置，原存档保留。
图标位置按 Shell 路径识别，存入同一布局文件；设置单独写入 `%LOCALAPPDATA%/PaneSpace/settings.json`。

## 当前限制

- 视口使用主屏，尚未实现多显示器画布。
- 无限模式取消镜头边界，自动排列仍在九屏区域执行；放不下时保留原布局。
- 缩放时浏览实时预览，回到 100% 后操作应用；缩放比例临时生效，不写入存档。
  有限模式回到 100% 时镜头会限制在画布边界内。最小化窗口仍可通过小地图定位。
- 受保护或无法预览的窗口内容可能显示占位提示，点击即可打开原窗口。
- 任务栏和壁纸保持固定；开启桌面图标选项后，图标参与画布。
- 画布图标支持拖动和双击打开；其他文件操作通过文件资源管理器完成。
- 最大化窗口平移时可能表现不自然；完全移出屏幕的应用可能暂停绘制。
- 隐藏、最小化窗口不参与自动排列。
- 退出收回时保持窗口尺寸；窗口超过屏幕工作区大小时，将左上角及标题栏搬回可见范围。
